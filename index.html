Búsqueda en APIs Públicas

Aplicación desarrollada con HTML, CSS y JavaScript para realizar búsquedas en diferentes APIs públicas y mostrar los resultados dinámicamente mediante tablas HTML.

1. PokéAPI

Escribe el nombre o ID de un Pokémon para consultar su información.

2. Open-Meteo

Escribe el nombre de una ciudad para consultar sus condiciones meteorológicas actuales.

3. Dog API

Escribe el nombre de una raza o subraza de perro.
